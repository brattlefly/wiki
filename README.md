# BrattleFly Wiki

Internal reference for running BrattleFly LLC — entities, brand rules, people, operations, marketing, and what's coming next.

## How to edit this wiki

Every page here is a markdown file in the `brattlefly/wiki` GitHub repo. To make a change:

1. Go to the repo on GitHub.
2. Open the file for the page that needs updating.
3. Click the pencil (edit) icon.
4. Make the change, scroll down, commit directly to `main`.
5. The site rebuilds automatically within a minute or two.

No local setup, no git command line required for quick edits — GitHub's web editor handles it.
